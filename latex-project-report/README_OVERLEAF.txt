Overleaf instructions
====================

1. Go to https://www.overleaf.com and create a new blank project.
2. Upload the whole latex-project-report folder (report.tex, report.bib,
   chapters/, figures/, screenshots/).
3. Set the main document to report.tex.
4. Compiler: pdfLaTeX. Recompile twice so the table of contents and
   bibliography settle.

The project title on the cover is:

  GestureTalk: Real-Time Sign Language Recognition, Text Conversion
  and Speech Generation System

If Overleaf asks for a bibliography run, click Recompile again.
If a screenshot is missing, check that screenshots/ was uploaded.
